Header là Global Component.

Không bao giờ lấy Header của một trang để ghi đè Header của toàn bộ project.

Mỗi lần có Header mới phải:

1. So sánh với Header hiện tại.

2. Liệt kê toàn bộ tính năng.

Ví dụ:

Header A

✓ Logo
✓ Search
✓ Notification
✓ Cart
✓ User

Header B

✓ Logo
✓ Search
✓ Language
✓ Theme
✓ User

=> Sinh Header C

✓ Logo
✓ Search
✓ Notification
✓ Cart
✓ Language
✓ Theme
✓ User

Nếu hai Header có cách bố trí khác nhau.

Hãy chọn layout đẹp hơn.

Nếu icon khác nhau.

Chọn icon trực quan hơn.

Nếu khoảng trắng khác nhau.

Chọn spacing hợp lý hơn.

Không được làm mất tính năng cũ nếu không có lý do rõ ràng.

Header luôn được xem là phiên bản Enterprise cuối cùng.
