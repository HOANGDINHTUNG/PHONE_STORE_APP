# Testing

Lưu test strategy, test plan, quality gate, coverage rationale và evidence quan trọng.

## Quy tắc

- Requirement/risk quan trọng phải truy ngược được đến test.
- Tách unit, slice, integration, contract, security và performance.
- Ghi môi trường/container version và cách tái hiện.
- Không lưu test credential production.
- Flaky/disabled test phải có owner và kế hoạch xử lý.
