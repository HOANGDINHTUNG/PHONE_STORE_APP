# Requirements

Nguồn sự thật cho yêu cầu nghiệp vụ và phi chức năng đã được xác nhận.

## Quy ước

- Mỗi requirement có ID ổn định: `FR-xxx` hoặc `NFR-xxx`.
- Ghi actor, precondition, flow, exception và acceptance criteria kiểm thử được.
- Phân biệt `Confirmed`, `Proposed`, `Deprecated`.
- Liên kết requirement đến API, ADR và test.
- Không chép implementation detail vào business requirement.
- Thay đổi scope phải ghi owner, ngày và ảnh hưởng.

Bắt đầu từ [SRS-TEMPLATE.md](SRS-TEMPLATE.md).
