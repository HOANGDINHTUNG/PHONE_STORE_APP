# Architecture Decision Records

Tạo ADR cho quyết định có trade-off lớn hoặc khó đảo ngược: module boundary, consistency, auth/token, ID, database strategy, provider, caching, event/outbox và deployment.

## Quy ước

- Tên: `NNNN-short-title.md`.
- Status: Proposed, Accepted, Superseded, Deprecated.
- Không sửa lịch sử quyết định đã Accepted để che thay đổi; tạo ADR mới và liên kết supersedes.
- Ghi bằng chứng và hệ quả, không chỉ kết luận.

Sao chép [0000-adr-template.md](0000-adr-template.md) và cấp số tiếp theo.
